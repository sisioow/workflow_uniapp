# 测试检查清单 - 栈溢出修复验证

## 环境准备
- [ ] 清空浏览器缓存
- [ ] 打开浏览器开发者工具 (F12)
- [ ] 打开 Console 标签页，记录是否有任何 JS 错误

## 测试场景 1: 项目列表显示
**目标:** 验证项目列表正常渲染，事件绑定正确

- [ ] 打开应用，观察项目列表是否显示
- [ ] 项目列表自动刷新（每 5 秒）
- [ ] 项目步骤显示正确（显示 emoji + 文字）
- [ ] 当前活跃项目有 "active" 类高亮
- [ ] Console 中无错误或警告

## 测试场景 2: 快速项目切换
**目标:** 验证不会发生栈溢出

**步骤:**
1. 创建项目 A（应用名：TestA）
2. 创建项目 B（应用名：TestB）
3. 创建项目 C（应用名：TestC）

**操作序列:**
```
A → B → C → A → B → C → A
(快速点击，间隔 1-2 秒)
```

**验证项:**
- [ ] 无 "Maximum call stack size exceeded" 错误
- [ ] 无其他 JS 错误
- [ ] 每次切换后项目高亮正确更新
- [ ] 项目步骤信息正确显示
- [ ] Console 中仅显示预期的日志信息

## 测试场景 3: 失败状态项目切换
**目标:** 验证错误项目的处理和切换

**步骤:**
1. 创建项目并让其在"分析"步骤失败
   - 手动将项目状态设置为 error（通过 API 或开发者工具）
2. 创建另一个正常项目
3. 在失败项目和正常项目间切换

**验证项:**
- [ ] 失败项目显示 "❌ 错误" 标志
- [ ] 切换到失败项目时，显示错误信息和重试按钮
- [ ] 可以点击"重试"按钮
- [ ] 切换到正常项目时，错误信息隐藏
- [ ] 无栈溢出或其他错误

## 测试场景 4: 项目删除
**目标:** 验证删除功能不影响栈溢出修复

**步骤:**
1. 创建 3 个测试项目
2. 删除第一个项目
3. 删除第二个项目
4. 删除第三个项目
5. 创建新项目

**验证项:**
- [ ] 每次删除后，列表更新正确
- [ ] 如果删除的是当前项目，自动切换到其他项目
- [ ] 删除最后一个项目后，显示 "暂无项目" 且返回初始界面
- [ ] 新建项目时无错误
- [ ] 无栈溢出或其他错误

## 测试场景 5: 项目刷新
**目标:** 验证定时刷新不会导致问题

**步骤:**
1. 创建 2 个项目
2. 观察项目列表自动刷新（每 5 秒）
3. 在刷新发生时切换项目

**验证项:**
- [ ] 项目列表每 5 秒自动更新一次
- [ ] 自动刷新期间切换项目无问题
- [ ] 高亮显示正确
- [ ] 无栈溢出或其他错误

## 测试场景 6: 计划列表选择
**目标:** 验证 renderPlanList 递归修复有效

**步骤:**
1. 完成到"选择方案"步骤（需要至少 2 个设计成功的方案）
2. 点击不同的方案卡片切换选择

**验证项:**
- [ ] 点击方案卡片时，选中状态更新
- [ ] UI 类名更新正确
- [ ] 无栈溢出或递归错误
- [ ] Console 中无额外的 renderPlanList 调用日志

## 测试场景 7: 并发操作
**目标:** 验证多个操作同时发生时的稳定性

**步骤:**
1. 创建 3 个项目到不同的步骤
2. 快速在项目间切换
3. 同时点击删除和切换
4. 快速连续点击同一项目

**验证项:**
- [ ] 操作有序处理
- [ ] 无栈溢出或竞态条件错误
- [ ] UI 状态最终一致性正确

## 测试场景 8: SSE 事件处理
**目标:** 验证 applyState 包装不会导致事件风暴

**步骤:**
1. 创建项目并启动工作流
2. 观察 SSE 消息处理
3. 多个状态更新同时发生时的表现

**验证项:**
- [ ] SSE 消息正常处理
- [ ] 每个状态更新只渲染一次
- [ ] 项目列表高亮在定时刷新时更新（不在每个状态变化时更新）
- [ ] Console 中 SSE 日志正常
